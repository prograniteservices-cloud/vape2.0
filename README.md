# VapeOS v2 (Temp Vape)

An intelligent product discovery and inventory management platform for vape shops, leveraging AI-powered capabilities.

## Tech Stack
- **Framework**: Next.js 16.1.6 (Experimental)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4, Framer Motion
- **AI**: Google Generative AI (@google/generative-ai)
- **UI Components**: lucide-react, class-variance-authority

## Key Features
- **AI-Powered Product Discovery**: Intelligent chatbot interface for searching and recommending products.
- **Dynamic Inventory Management**: Prototype for managing 100+ product categories.
- **Modern UI**: Polished dark-themed interface with high-performance animations.
- **Micro-interactions**: Framer Motion-powered interactive elements.

## Status
- Core framework and AI integration in place.
- Experimental Next.js 16 usage.

## How to Use

### In React/Next.js Components:
```jsx
<img 
  src={`https://placehold.co/300x400/FF6B6B/FFFFFF?text=${product.name}`} 
  alt={product.name}
/>
```

### With Dynamic Sizing:
```jsx
<img 
  src={`https://placehold.co/${width}x${height}/${color}/FFFFFF?text=${text}`} 
  alt={product.name}
/>
```

### Available Sizes:
- `300x400` - Portrait (recommended for products)
- `400x300` - Landscape
- `300x300` - Square
- `600x800` - Large portrait
- Any custom dimensions work
